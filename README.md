# Программа обмена значениями переменных (C++)

Данная программа меняет местами значения двух целочисленных переменных `a` и `b` с использованием временной переменной.

## Как это работает
1. Изначально `a = 3`, `b = 5`.
2. Значение `a` сохраняется во временную переменную.
3. В `a` записывается значение `b`.
4. В `b` записывается сохраненное значение.

## Результат работы
```text
Новое значение a = 5
Новое значение b = 3
